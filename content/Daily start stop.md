# Daily Startup / Shutdown

## 🟢 Daily Startup
> [!tip] Startup
> - Review Today’s Efforts (Rank 1 + Rank 2)
> - Choose one Effort to touch
> - Clear one micro‑zone (10–20 seconds)
> - Set a simple intention for the day
> - Open Daily Anchor note

## 🔴 Daily Shutdown
> [!check] Shutdown
> - Write one line per Effort touched
> - Update Last → Next on each Effort card
> - Reset any micro‑zones you used
> - Capture one insight into the Idea Garden
> - Close the day with a slow breath
