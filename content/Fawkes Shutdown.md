
> [!check] Shutdown Ritual
> - Update Effort Card (Last → Next)
> - Commit and push any changes:
>   - `git add .`
>   - `git commit -m "progress note"`
>   - `git push`
> - Document what you learned (Idea Garden)
> - Capture any new issues or TODOs in GitHub
> - Close the dev environment cleanly
> - Reset your physical micro‑zone (desk, notes)

> [!note] Evidence Base
> - Writing “Next” reduces restart friction (Zeigarnik effect)
> - Clean shutdown prevents technical debt
> - Capturing insights improves long‑term retention
