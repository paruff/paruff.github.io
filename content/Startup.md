# Effort Startup

> [!tip] Startup Ritual
> - Review the Effort card (Last → Next)
> - State a clear intention for this session
> - Clear the micro‑zone (10–20 seconds)
> - Touch the physical marker for this Effort
> - Open the Effort page in Obsidian
> - Choose one tiny, finishable action

> [!note] Evidence Base
> - Intention setting improves follow‑through (implementation intentions research)
> - Micro‑cleaning reduces cognitive load (environmental psychology)
> - Physical cues increase task recall (context‑dependent memory)
> - Small actions build momentum (behavioral activation)
