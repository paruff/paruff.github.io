# Mindfulness Shutdown

> [!check] Shutdown Ritual
> - Note one observation from the session (neutral, factual)
> - Notice any change in physical or mental state
> - Take one slow breath to close the practice
> - Write one line in Daily Anchor (“Mindfulness: observed X”)
> - Transition gently to the next Effort

> [!note] Evidence Base
> - Reflection consolidates attentional learning
> - Observing state changes increases interoceptive accuracy
> - Slow exhale activates parasympathetic response
> - Brief journaling improves habit retention
